Sound effects are chess.com's default-theme sounds, downloaded from their
public CDN (images.chesscomfiles.com/chess-themes/sounds/_MP3_/default).

Mapping (target file <- chess.com source):
  move.mp3     <- move-self.mp3
  capture.mp3  <- capture.mp3
  check.mp3    <- move-check.mp3
  castle.mp3   <- castle.mp3
  promote.mp3  <- promote.mp3
  start.mp3    <- game-start.mp3
  complete.mp3 <- game-end.mp3
