Sound effects sourced from the Lichess project (lichess-org/lila),
https://github.com/lichess-org/lila (public/sound).

Mapping (target file <- Lichess source):
  move.mp3     <- standard/Move.mp3
  capture.mp3  <- standard/Capture.mp3
  error.mp3    <- standard/Error.mp3
  promote.mp3  <- standard/Confirmation.mp3
  start.mp3    <- standard/GenericNotify.mp3
  castle.mp3   <- sfx/Move.mp3
  check.mp3    <- sfx/Check.mp3
  complete.mp3 <- sfx/Victory.mp3
